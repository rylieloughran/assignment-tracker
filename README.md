# assignment-tracker
Assignment Tracker: designed to help students keep track of their assignments and their due dates, courses, and urgency.

Features:
- Add assignments
- Track due dates
- Track course names
- Set assignment urgency
- Set an estimate how long an assignment will take
- Sort and filter assignments
- Add subtasks to assignments

How to run:
1. Open in VSCode
2. Run DemoApplication.java
3. Open index.html with Live Server
